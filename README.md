# Имитация отжига · учебная демонстрация (Vite + React)

Интерактивная визуализация метаэвристического алгоритма **Simulated Annealing**
на трёх задачах с переключателем:

1. **Коммивояжёр (TSP)** — кратчайший маршрут по городам. Можно кликать по полю и добавлять города.
2. **Минимум функции (1D)** — глобальный минимум «колючей» функции с множеством локальных ям.
3. **Рюкзак (0/1 Knapsack)** — максимум ценности при ограничении веса.

Для каждой задачи показаны: текущая/лучшая энергия, температура T, число итераций,
а также графики энергии и температуры в реальном времени.

## Запуск

```bash
npm install
npm run dev
```

Затем открой адрес, который выведет Vite (обычно http://localhost:5173).

Сборка production-версии:

```bash
npm run build
npm run preview
```

## Структура

```
src/
  algorithms/annealing.js   ← общий движок отжига (не зависит от задачи)
  problems/                 ← описание задач: initialState/energy/neighbor/clone
    tsp.js
    func1d.js
    knapsack.js
  components/               ← UI, графики, хук управления симуляцией
  App.jsx                   ← переключатель задач
```

Ключевая идея в `annealing.js`: ухудшающее решение принимается с вероятностью
`exp(-Δ / T)`. На высокой температуре прыжки частые (выход из локальных ловушек),
при остывании — всё реже (сходимость).

## Как расширить (идеи)

- Добавить **линейный/логарифмический** график охлаждения и сравнить с экспоненциальным.
- Режим «гонка»: запустить отжиг рядом с жадным алгоритмом и сравнить результат.
- Сохранение лучшего маршрута/набора в localStorage.
- Слайдеры для tStart / alpha прямо в UI, чтобы студенты сами крутили параметры.
- Четвёртая задача: раскраска графа или расписание (scheduling).
